العامري | الموقع الرسمي والمنصة الأدبية
====================================

الغرض
- الموقع الشخصي والأدبي المنشور عبر GitHub Pages.
- مكتبة تحتوي على 10 قصائد أصلية موثقة في poems.json، ولكل قصيدة صفحة ضمن poems/.
- استوديو كتابة عربي ومجتمع أدبي ودواوين ومراجعة أعمال، مع واجهة Supabase.

خريطة الملفات
- index.html: الصفحة الرئيسية.
- profile.png: الصورة الشخصية.
- poems.json و poems/AM-*.html: نصوص القصائد الأصلية وصفحاتها.
- studio/index.html: واجهة الاستوديو والدواوين والمجتمع والعضوية.
- studio/studio.js: منطق الواجهة والعضوية والمشاركات.
- studio/literary-modules.js: الدواوين والمسودات وسجل النسخ والمراجعة.
- studio/config.js: عنوان Supabase ومفتاح publishable العام فقط.
- backend/schema.sql: قاعدة البيانات وأدوار الأعضاء.
- backend/migrations/: قواعد دورة اعتماد الدواوين والقصائد.
- sitemap.xml و robots.txt: مساعدة اكتشاف الصفحات لمحركات البحث.
- scripts/check-integrity.mjs: فحص محافظ على القصائد الأصلية وبنية المنصة.

التشغيل والمراجعة
1. افتح index.html في متصفح حديث أو استخدم استضافة ثابتة.
2. يحتاج الاستوديو إلى اتصال بالخدمة وقاعدة بيانات Supabase لتفعيل العضوية.
3. لا تضع مفاتيح service_role أو بيانات SMTP أو كلمات المرور في ملفات الموقع العامة.
4. لتشغيل فحص سلامة المشروع: node scripts/check-integrity.mjs (Node.js 18 أو أحدث).
5. يُحفظ المصدر الأصلي لجميع القصائد دون تغيير؛ أي تصحيح أدبي يتطلب موافقة صاحب النص.

النشر
- موقع GitHub Pages: https://ahmedghazwoane8125-prog.github.io/alameri-official/
- يتضمن المشروع أيضًا إعدادات لموقع Vercel؛ يلزم اختيار عنوان أساسي موحد للموقع.
- لا يثبت نجاح حفظ الملفات في GitHub أن كل الوظائف ديناميكيًا تعمل على الهاتف.
- فرع audit/literary-platform-hardening-20261105 مخصص للمراجعة والإصلاحات، ولا يُدمج مع main أو يُنشر للإنتاج دون موافقة صاحب المشروع.

الأمان والاعتماد
- العضوية العادية لا تمنح رتبة شاعر.
- الدواوين والقصائد الجديدة تبدأ بمسودات خاصة وتخضع لاعتماد المدير الصريح.
- خدمة واتساب للتحقق OTP غير مُفعّلة؛ الرقم الموجود في الملف الشخصي غير متحقق منه.
- مطلوب SMTP مناسب قبل استقبال تسجيلات الجمهور.
- حماية نسخ النصوص عبر JavaScript ليست نظام حقوق أو وصول محكم للصفحات العامة.

للتفاصيل: راجع backend/SETUP_AR.md و backend/PROGRESS_LITERARY_AR.md وتقرير التدقيق في AUDIT_REPORT_AR.md.
