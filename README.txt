العامري | الموقع الرسمي
========================

الملفات
- index.html: الصفحة الرئيسية للموقع
- profile.png: الصورة الشخصية الأصلية بدون تعديل

التشغيل المحلي
افتح index.html في متصفح حديث بعد فك الضغط مع إبقاء profile.png بجانبه في المجلد نفسه
الأزرار التي تشير إلى الشبكات الاجتماعية تعمل بالإنترنت
أما أزرار نسخ رابط الموقع ومشاركته فتحتاج لنشره أولا بعنوان https حقيقي

النشر عبر GitHub Pages
1 افتح GitHub وأنشئ مستودعا جديدا وليكن alameri-official
2 ارفع index.html و profile.png إلى جذر المستودع
3 افتح Settings ثم Pages ثم Build and deployment
4 اختر Deploy from a branch وحدد main و /(root) واضغط Save
5 بعد تفعيل Pages يصبح الموقع متاحا بعنوان مشابه:
  https://USERNAME.github.io/alameri-official/

لا توجد قصائد أو كتب مدخلة حاليا حتى لا تنشر نصوص غير معتمدة
